## 💡 Claude Code / MCP 関連

- **バックグラウンド `/code-review` 対応**: コードレビューをバックグラウンドで実行できるよう改善。スクリーンリーダーのフィードバック強化、オートモードとトラスト処理の安全性向上。
  - 出典: [Claude Code Updates - July 2026](https://releasebot.io/updates/anthropic/claude-code)

- **MCP のパス解決改善**: managed MCP の allowlist/denylist における `${VAR}` エントリを、設定ファイル env ではなく起動時環境・managed-settings env から解決するよう変更。Windows パス処理も改善。
  - 出典: [Claude Code Changelog (July 2026)](https://www.gradually.ai/en/changelogs/claude-code/)

- **サブエージェント多段ネスト対応**: サブエージェントがデフォルトで深さ3まで子サブエージェントをスポーン可能に（従来は深さ1）。無効化は環境変数 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` で設定可能。
  - 出典: [Claude Code Updates - July 2026](https://releasebot.io/updates/anthropic/claude-code)

- **絵文字ショートコードオートコンプリート追加**: プロンプト入力欄で `:heart:` と入力すると ❤️ に変換、`:hea` で候補を表示する機能を追加。
  - 出典: [Claude Code Changelog (July 2026)](https://www.gradually.ai/en/changelogs/claude-code/)

- **最新バージョン**: v2.1.218（7月22日リリース）
  - 出典: [Claude Code Changelog (July 2026)](https://www.gradually.ai/en/changelogs/claude-code/)
